# Helping Hands Organization

[GitHub](https://github.com/bantupallisarath7/Helping-Hands-Organization-Web-Application) • [Live](https://helping-hands-organization-web-appl.vercel.app/)

## Overview
Helping Hands Organization is a role-based MERN stack web application for managing fundraising campaigns, donations, events, and user interactions. It enables organizations to efficiently handle campaign lifecycles and donor contributions.

---

## Features

- **User**
  - Sign up / log in
  - Create and track campaigns (Pending → Approved → Funded/Rejected)
  - View and manage donations
  - Submit donation receipts

- **Admin**
  - Approve/reject campaigns
  - Manage donation receipts
  - Manage events, gallery, and users

- **Authentication**
  - Secure login with role-based access control

---

## Tech Stack

- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT  

---

## Key Highlights

- Role-based system (User & Admin)  
- Complete campaign lifecycle management  
- Donation and receipt verification workflow  
- Structured RESTful backend architecture  

---

## Installation

```bash
# Clone repo
git clone https://github.com/bantupallisarath7/Helping-Hands-Organization---Web-Application.git

# Backend
cd backend
npm install
npm run dev

# Frontend
cd ../frontend
npm install
npm start
```
